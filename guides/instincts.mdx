An instinct stores a trigger, an action, confidence, source, and verification state. The runtime injects only its `action`. It does not match the trigger against the task.

## Add an action

```bash
orchestos instinct add --trigger "Billing convention" --action "Use src/billing/stripe.ts for Stripe calls"
```

Manual instincts start at confidence `1.0`, source `manual`, and `verified: true`. Use `--confidence <0-1>` to set a different confidence.

The current `instinct add` command does not attach the current project ID. It creates an unscoped record, which the project-scoped runtime does not inject. `instinct propose` and run analysis do attach the registered project ID.

```bash
orchestos instinct list
orchestos instinct list --unverified
orchestos instinct list --source manual
```

## Propose and review

```bash
orchestos instinct propose --trigger "Repeated billing failure" --action "Check the shared Stripe client before changing billing"
orchestos instinct review
orchestos instinct approve <id>
orchestos instinct reject <id>
orchestos instinct set-confidence <id> 0.9
```

Proposals start at confidence `0.6`, source `auto`, and `verified: false`. Approval sets verification to true and confidence to `min(max(confidence + 0.1, 0.8), 1.0)`. Rejection deletes the instinct.

Setting confidence below `0.6` clears verification. Raising it again does not verify an unverified instinct; approve it explicitly.

## Learn from runs

```bash
orchestos runs --analyze --last 20
```

Analysis needs at least three runs and uses the Auxiliary role. A suggested pattern must have frequency at least `3` to create an instinct proposal. Proposals deduplicate trigger text within the project after trimming and lowercasing. They still need approval before runtime application.

## Runtime application

The middleware chain is `skillRoute → roadmapContext → contextInject → instinctApply`.

The last step selects instincts for the registered project with `verified: true` and confidence at least `0.8`. It injects every selected action, ordered by confidence and creation time. It does not evaluate trigger text. If the project is not registered, no instincts are applied. Instincts without a project ID are not runtime fallbacks.
