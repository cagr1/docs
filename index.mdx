OrchestOS is a local dashboard and CLI that orchestrates the coding CLIs you already use — Claude Code, Codex, OpenCode. You ask in a chat; the orchestrator turns the request into a task with a declared file contract, an executor writes only those files inside a git worktree, deterministic checks and a QA reviewer validate the result, and the outcome comes back to the same chat thread. Every run leaves evidence in SQLite.

## Get up and running

<Steps>
  <Step title="Install OrchestOS">
    Install Bun, clone the repository, then run `bun install` and `bun run build:app`.
  </Step>
  <Step title="Open the dashboard">
    Run `orchestos dashboard` and open `http://localhost:4242`. Add a local git repository from the sidebar.
  </Step>
  <Step title="Assign the four roles">
    In **Settings → Model routing**, pick agent, model, and effort for each role. You need no API key if every role uses a CLI you are already logged into.
  </Step>
  <Step title="Ask for a change">
    Switch to **Dev** mode and describe what you want. The orchestrator drafts a task with its `output[]` contract and runs it.
  </Step>
</Steps>

## What makes OrchestOS different

<CardGroup cols={3}>
  <Card title="File contracts" icon="file-contract" href="/concepts/contracts">
    Each task declares `output[]` — the only files the executor may write. Anything outside that list is blocked, logged, and fails the run.
  </Card>
  <Card title="Git worktree sandbox" icon="code-branch" href="/concepts/sandbox">
    Each task runs in an isolated git worktree. It merges back only after checks and QA pass; on failure the worktree is discarded.
  </Card>
  <Card title="Your CLIs, your plan" icon="plug" href="/reference/models">
    Roles run on `claude`, `codex`, or `opencode` with your own subscription. API keys are optional.
  </Card>
</CardGroup>
