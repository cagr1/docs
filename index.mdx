OrchestOS turns chat requests into coding tasks with declared output files. You choose agents and models, run work in a git worktree when available, and inspect checks, review results, and file evidence in the same dashboard.

## Start working

1. Clone the repository and run `bash install.sh`. On Windows, use `install.ps1` or `install.bat`: **Experimental — not yet tested on Windows**.
2. Open the URL printed by the CLI, including `#t=<token>` on your first visit.
3. Add a project and assign roles in **Settings → Model routing**.
4. Switch to **Dev**, describe a change, and review its task card.

Worktree execution requires a clean git tree. A task touching existing files waits for **Approve & Run**; a dirty tree offers **Commit & Run**. Interrupted tasks offer **Resume**.

Checks run before LLM review. The reviewer runs when acceptance criteria, an applicable review gate, or your noncoding profile requires it. Otherwise the run records that QA was skipped. See [Introduction](/introduction) for contracts, sandbox fallbacks, and evidence.
